# Matrx 新消息检测

只做一件事:返回 Matrx 本地推送缓存(`PushCache.sqlite*`)的最新修改时间。

- 输出 JSON:`{"latest": <最新 mtime 整数秒>, "count": <文件数>}`。
- 本地库端到端加密、读不了内容,但 **mtime 是元数据、随便读**;新消息一来 mtime 就变,足够做"有新消息"信号。
- **无需任何系统权限**(不同于读通知中心数据库 / 抓通知横幅)。
- App 记住上次的 `latest`,变大即提醒;首次轮询只记基线、不提醒。

> 装了 Matrx 才有意义。不想要就删掉本文件夹(App 检测不到本 skill 就不轮询)。
> 局限:mtime 变动也可能来自同步/已读回执等,不一定每次都是"别人发来的新消息",但胜在零权限、零风险。
