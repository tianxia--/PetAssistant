> 从今往后,开发调试都在 `~/Desktop/PetAssistant`。本项目**完全自包含**,不依赖 `~/.claude`。

```
PetAssistant/

├── docs/
│   ├── 需求与设计.md       # 完整设计、路线图、教训
│   └── 项目地图.md         # 本文件
├── pet-app/               # ★ 桌面宠物 App(主要开发对象)
│   ├── Package.swift
│   ├── Sources/ErDanPet/main.swift   # 原生壳:悬浮窗/游走/两态窗口/Agent大脑/工具/提醒
│   ├── web/
│   │   ├── pet.html       # 交互:待机↔对话两态、气泡、聊天卡片、设置、主题
│   │   ├── engine.js      # 插画骨骼动画引擎(逐帧变换分组)
│   │   ├── dragon.svg     # 形象素材(换皮改这个,保留分组 id)
│   │   └── candidates/    # 历史形象候选
│   ├── start_pet.sh       # 一键构建+启动
│   └── README.md          # App 说明
├── skills/                # ★ 动态技能(丢文件夹即加,详见 skills/README.md)
│   ├── branch-report/     # 采集仓库分支增量(自包含:gather.sh + data/)
│   ├── matrx-send/        # 发 Matrx 群(自包含:run.py + webhook.conf)
│   └── daily-report/      # 每日日报:采集→写报告→发群(宠物内置定时器 09:03 自动触发)
└── pet-data/              # ★ 二蛋的记忆(唯一事实源)
    ├── inbox.md / tasks.md / about-you.md / daily/
```

## 开发调试工作流(都在本目录)

```bash
cd ~/Desktop/PetAssistant/pet-app

swift build                 # 编译
zsh start_pet.sh            # 构建并(重)启动桌面宠物,日志 /tmp/erdanpet.log
tail -f /tmp/erdanpet.log   # 看运行日志

# 只调页面/动画,不用原生壳:浏览器打开预览(演示模式,自动走跑跳、假回复)
open pet-app/web/pet.html   # 或用本地静态服务器 + ?demo=1
```

- **改形象**:替换 `web/dragon.svg`(保留分组 id:tail/body/belly/arms/head[eyes/mouth/ears/horns/mane])。
- **改动画**:`web/engine.js`。
- **改交互/布局**:`web/pet.html`。
- **改大脑/工具/窗口**:`Sources/ErDanPet/main.swift`,改完 `swift build` + `zsh start_pet.sh`。
- **加技能**:在 `skills/` 下新建文件夹(`skill.json` + 脚本),重启生效。

## 与 `~/.claude` 的关系(重要)

本项目**不再依赖** `~/.claude`。那里剩下的是 **Claude Code CLI 自己的东西**,和宠物无关,保留即可:

| `~/.claude` 下的东西 | 归谁 | 宠物是否需要 |
|---------------------|------|------------|
| `skills/branch-report/`、`branch-report/`(旧 repos/cache/脚本) | 早期 Claude Code CLI 用 | ❌ 已弃用,宠物自带副本 |
| 每日报告 cron `c98c4f4b` | 旧的 Claude Code 定时任务 | ❌ **已删除**,改由宠物 App 内置定时器 |
| `projects/.../memory/` | Claude Code 会话记忆 | ❌ 与宠物无关 |

> 每日日报已**完全搬进宠物**:`skills/daily-report/` 做事,宠物 App 内置定时器(`dailyReportTime`,默认 09:03)触发,不再需要 cron / launchd / claude CLI。branch-report / matrx 也都是 `PetAssistant/skills/` 下的独立副本。改宠物只动 `PetAssistant/`。
